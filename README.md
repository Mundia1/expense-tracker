# Expense Tracker

A React application for tracking expenses, built for SA.01 Week 1 Code Challenge.

## Setup

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.

## Deployment

- **Vercel**: Deploy using `vercel` command or Vercel dashboard.
- **Netlify**: Deploy using Netlify CLI or dashboard.

## File Structure

- `src/components/`: UI, feature, and layout components.
- `src/hooks/`: Custom hooks for filtering and sorting.
- `src/utils/`: Helper functions.
- `src/styles/`: Global and reset styles.
